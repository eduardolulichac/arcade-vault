## Project

Arcade Vault: a platform for playing games online and competing for the highest score (see README.md). The repository is currently a fresh `create-next-app` scaffold — `app/page.tsx` and `app/layout.tsx` still hold the default template content, and no application code has been written yet.

The project intends to follow a Spec Driven Design workflow (specs in `/spec`, implementation notes in `/spec-impl`) using the skill set from https://github.com/Klerith/fernando-skills, installed via:

```bash
npx skills@latest add Klerith/fernando-skills
```

Neither the `/spec` directories nor the skill files exist in the repo yet — check for them before assuming the workflow is set up.

There is no test runner configured yet.

## Architecture notes

- Next.js 16.3.3 App Router, React 19, TypeScript (`strict: true`), Tailwind CSS v4 (imported via `@import "tailwindcss"` in `app/globals.css`, no `tailwind.config`).
- Path alias `@/*` maps to the repo root (`tsconfig.json`).
- **Next.js 16 has breaking changes vs. training data.** Before writing any App Router code, read the relevant guide under `node_modules/next/dist/docs/01-app/` and heed deprecation notices — see `AGENTS.md` for details.
